# BATON 기능명세서 v3.2

기준일 . 최신 제출 화면설계서와 PM 후속 확인을 반영했다. 포함 기능 31개·화면 ID 24종이다. 역할·상태별 시안은 별도 기능으로 중복 산정하지 않는다. 기능 ID와 화면 ID는 기존 식별자를 유지한다.

기존 문서의 매니저 대타 참여·근무 수정·변경 이력·처리 대기 탭 설명은 본 개정으로 대체한다. 다른 페이지와 충돌하면 이 개정 범위를 우선 확인한다. 다른 PRD·정책·화면설계 페이지 본문은 이번 작업에서 변경하지 않았다.

매장 나가기는 현재의 예정 근무 안내를 유지한다. 소속 없는 계정 복귀·반복 기간·알림 읽음과 수신·정렬·보관·소속 해제 시 요청 정리·탈퇴 파기는 정책서 v2.0을 적용한다. 남은 미정은 마지막 매니저 특수 처리·약관 본문·출시 플랫폼이다. 시안 숫자는 운영 제한이 아니다.

| SCH-01 | CA-01 / CA-02 | 매니저·크루원 | 내 근무·전체 근무 달력 | 내/전체 근무를 전환하고 이전·다음 달 및 오늘로 이동한다. 달력에는 날짜별 중복 제거한 근무 인원수를 표시한다. 내 근무 아래 목록은 표시 중인 월 전체를 따라간다. 내/전체 탭은 선택과 좌우 스와이프 모두 지원하며 같은 탭 상태로 동기화한다. | 월·선택일·로그인 사용자, 날짜별 인원수·월 근무 목록 | 날짜를 눌러도 내 근무 월 목록을 하루로 줄이지 않는다. 로딩·0건·실패를 구분한다. 매니저 하단 메뉴는 근무표·프로필 및 추가(+), 크루원은 근무표·요청·프로필이다. | 본인·소속 매장 기준으로 실제 데이터에서 인원과 목록을 계산한다. 시안의 날짜·12개 등 예시 수치는 고정값으로 사용하지 않는다. |

| WAITING | 이미 거절한 지정 크루원 | 수락 | 진행 중일 때만 재수락 가능. 종료 뒤 재개 없음. |
| WAITING / PENDING\_MANAGER | 요청 크루원 | 요청 취소 | CANCELLED. 원래 담당자 유지. |
| PENDING\_MANAGER | 현재 후보 크루원 | 수락 철회 | WITHDRAWN. 자동 재모집 없음. |
| PENDING\_MANAGER | 소속 매니저 | 최종 승인 / 거절 | APPROVED 때만 담당자 변경. 거절은 REJECTED. |
| PENDING\_MANAGER | 후보 아닌 지정 크루원 | 상태 조회 | 수락·거절·철회 버튼 없음. |
| 종료 | 접근 가능한 관계자 | 결과·진행 기록 조회 | 처리 버튼 없음. |
| 진행 중 | 시작 시각 도달 | 자동 만료 | EXPIRED. 수락·승인 불가. |
| 진행 중 | 근무 삭제 | 요청 종료 | 기존 SOURCE\_CHANGED에 삭제 사유를 연결. 근무 수정 시나리오는 제외. |
| 진행 중 | 요청자 소속 해제 | 요청 취소 | CANCELLED / REQUESTER\_LEFT. 원래 담당자 유지. |
| PENDING\_MANAGER | 후보 소속 해제 | 수락 철회 | WITHDRAWN / CANDIDATE\_LEFT. 자동 재모집 없음. |
| WAITING | 지정 대상 소속 해제 | 해당 대상만 응답 불가 | 나머지는 유지. 응답 가능한 대상 0명이면 CANCELLED / NO\_ACTIVE\_TARGET. |

수락 전에는 후보가 없고 첫 수락 후에는 후보 한 명만 존재한다. 최종 승인 전 담당자는 원래 담당자다. 종료 결과의 과거 수락·처리 사실은 요청 진행 기록으로 구분하며, 삭제한 근무의 정보는 삭제 전 정보임을 표시한다. 최종 상태 코드의 API 표기는 기존 계약과 맞추되 삭제 종료를 근무 수정 기능으로 해석하지 않는다.
